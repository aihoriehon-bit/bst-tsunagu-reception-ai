# Leda 3D audition

受付本体・比較版と独立した静的な試聴ページ。`/leda-3d/`を公開する。

- 既存GLB、顔パーツ、背景、`voice-comparison/audio/leda-{startup,route,confirm,goodbye}.wav`を参照。音声の再生成・課金APIは不要。
- avatar.jsのモデル配置・顔位置・机・既存アニメーションは既存Achernar試聴版から独立コピー。カメラ・顔認証・会話コードは含めない。
- ボタンの操作内で同じaudio要素を無音再生してモバイルの再生許可を準備→立ち上がり→声を再生→着席。お見送りの終わりはお辞儀を挟む。
- Web Audioで再生音声の音量を読み、口の開閉に使用。マイクを取得しない。分析非対応時は再生時間に合わせた簡易開閉。
- 連打・停止・ページ非表示は世代番号で古い再生待ちを破棄。自動再生・来客検出はしない。
- 正面固定カメラ、足は机の下でクリップ。PCはモデルと操作欄を左右、スマホは上下に分離する。
- 音声はGemini 3.8 Flash TTS / Leda。VOICEVOXやブラウザ音声へのフォールバックは行わない。

確認: `node --test leda-3d/page.test.mjs` とPC/スマホ幅の実画面で4パターン・停止・途中切り替え・帰席を確認する。
